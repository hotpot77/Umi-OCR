# 公路工程质检文控系统 — PRD（阶段 0）

## 1. 产品目标

合同段级 **工程划分（WBS）→ 工序签认（质检表）→ 审批待办** 闭环 Demo。  
对标华闽通达 GLAF 文控质检核心能力；用表体系采用 **交通部通用施表（JTG F80/1-2017 配套）**。

## 2. 范围（MVP = 阶段 0–3）

| 包含 | 不包含 |
|------|--------|
| 多角色登录 / RBAC / 多标段隔离 | 无编码平台 |
| 项目初始化 | 完整计量支付 |
| WBS 树 CRUD / Excel 导入 | BIM/GIS |
| 表单模板 + 实例填报 | 全量地方表 |
| 施工→监理签认（可退回） | 正式 CA 国密签章 |
| 待办首页 | 档案四性检测 |

## 3. 角色

| 角色码 | 名称 | 能力 |
|--------|------|------|
| `owner` | 业主 | 查看全局、统计 |
| `supervisor` | 监理 | 签认/退回质检任务 |
| `qc` | 质检员 | 填报、提交、查看本标段 |
| `worker` | 施工员 | 填报草稿、提交 |
| `archivist` | 资料员 | 查看文件、导出 |
| `admin` | 系统管理员 | 全部 |

## 4. 核心用户故事

1. 作为质检员，我能按 WBS 分项生成并填写施表。  
2. 作为监理，我能在待办中签认或退回。  
3. 作为施工员，我能看到退回原因并修改再提。  
4. 作为管理员，我能导入工程划分树并映射默认用表。

## 5. 状态机（质检任务）

```text
draft（草稿）
  → submitted（已提交/待监理审）
      → approved（已签认）
      → rejected（退回）→ draft
approved → archived（已归档，Demo 预留）
```

## 6. 验收标准

- [ ] 5 种角色可登录，数据按标段隔离  
- [ ] WBS 可增删改、Excel 导入  
- [ ] 至少 2 类模板：结构化（养护记录）+ 网格（平整度）  
- [ ] 填报→提交→签认/退回闭环可演示  
- [ ] 待办数量与列表口径一致
