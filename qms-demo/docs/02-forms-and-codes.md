# 施表字段字典 & Top50 清单（阶段 0）

> 用表体系：交通部通用施表（对齐 JTG F80/1-2017 常用表）。  
> Demo 实现前 2 张完整可填；其余列入清单作为后续资产。

## 1. Demo 已实现模板

### 1.1 施表-43 混凝土构件养护记录（structured）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| project_name | string | Y | 工程名称 |
| contractor | string | Y | 施工单位 |
| supervisor_org | string | N | 监理单位 |
| unit_工程 | string | Y | 单位工程 |
| div_工程 | string | Y | 分部工程 |
| component_name | string | Y | 构件名称 |
| pour_date | date | Y | 浇筑日期 |
| cure_method | enum[] | Y | 覆盖/喷雾/蓄水/洒水 |
| start_time | datetime | Y | 开始养护时间 |
| ambient_temp | number | N | 环境温度 ℃ |
| remark | string | N | 备注 |
| recorder | string | Y | 记录人 |

### 1.2 施表-100 路基路面平整度检测原始记录（grid）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| project_name | string | Y | 工程名称 |
| stake_from | string | Y | 起桩号 |
| stake_to | string | Y | 止桩号 |
| instrument | string | N | 仪器 |
| points | number[10] | Y | 10 个测点读数 (mm) |
| design_limit | number | Y | 允许偏差 |
| conclusion | string | N | 结论（自动） |

合格规则（Demo）：`max(|point|) <= design_limit` → 合格。
